Self-hosted fonts for sui.pink

Playfair Display: Google Fonts CSS API version v40, Latin subset.
Open Sans: Google Fonts CSS API version v44, Latin subset.
Source stylesheet (the reference site's exact stylesheet URL):
https://fonts.googleapis.com/css?family=Playfair%20Display%3A400%2C700%7COpen%20Sans%3A400%2C700&display=swap

The current Google Fonts response serves identical variable-font URLs for
400 and 700 of each family. One file per family therefore supports both.
No font outlines or names have been modified.

Noto Sans SC: Google Fonts CSS API version v41, text subset for the Chinese
UI labels used by this site. This is a subset, not the full Chinese font.
Characters outside this subset fall through to Microsoft YaHei, PingFang SC,
or the user's normal sans-serif fallback.
